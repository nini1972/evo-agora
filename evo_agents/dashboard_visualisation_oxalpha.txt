## Deel 1 — Chain of Thought: ontwerpoverwegingen vóór de dashboard-code

**Stap 0 — De simulatie is heilig; het dashboard is een consument.**
De belangrijkste architectonische beslissing staat vast vóór ik ook maar één regel UI denk: het dashboard mag de simulatie **nooit** beïnvloeden. Concreet betekent dat drie regels: (1) de observator leest alleen, schrijft nooit terug naar `Wereld`; (2) de telemetrielaag gebruikt géén RNG — anders breekt ik de reproduceerbaarheid die ik in de basisarchitectuur als invariant heb afgedwongen; (3) als er géén observatoren gekoppeld zijn, is de overhead ≈ één lelijke-lijstcheck per tick. Daarom kies ik voor het **observer-patroon** met een smal protocol (`na_tik`, `na_generatie`, `gebeurtenis`), niet voor logging aanroepen verspreid door de simulatielogica.

**Stap 1 — Wat is er überhaupt te zien? Drie informatielagen.**
Ik inventariseer wat de simulatie uniek maakt en welke vragen een onderzoeker erover wil beantwoorden:

- **Ruimtelijke laag**: waar zijn bronnen, wie jaagt wie, waar ontstaan handelsnetwerken? → kaartweergave.
- **Dynamische laag**: hoe bewegen populatie, genfrequenties, ongelijkheid en instituties door de tijd? → tijdsreeksen.
- **Evolutionaire laag**: convergeert het genoom? Verdwijnt diversiteit? Wint coöperatie of parasitisme? → generatiepanelen en faseportretten.

Cruciaal inzicht: de interessantste wetenschap zit in de **koppeling tussen lagen** — bijvoorbeeld de Lotka-Volterra-achtige cyclus tussen parasitaire druk en ecosysteemgezondheid. Daarom moet het dashboard een **faseportret** kunnen tekenen `(P_parasitair, EHI)`, niet alleen losse tijdsreeksen.

**Stap 2 — Metrieken moeten exact gedefinieerd zijn, niet "een indicatie".**
Een dashboard zonder formules is decoratie. Ik definieer daarom nu alvast, want de telemetrielaag gaat ze berekenen:

- **Welvaartsongelijkheid**: Gini-coëfficiënt over de ertsvoorraden, `G = (n+1 − 2·Σᵢ Cᵢ/Cₙ)/n` (Cᵢ = cumulatieve som, gesorteerd oplopend).
- **Fenotypediversiteit**: Shannon-entropy `H′ = −Σₖ pₖ ln pₖ` over de 9 fenotype-emmers (3×3-grid uit `fenotype_bucket`), plus het aantal greedy-clusters (δ = 0.35) uit de evolutiemotor.
- **Parasitaire druk**: `P = (1/N)·#{i : agressieᵢ > 0.6 ∧ coöperatieᵢ < 0.3}`.
- **Coöperatiegraad**: EMA κ over gebeurtenissen, `κ ← 0.92·κ + 0.08·w` met w = 1 voor geslaagde handelsafwikkelingen en w = 0 voor geslaagde overvallen. Dit is dé graadmeter voor de centrale onderzoeksvraag (wint coöperatie het van roof?).

**Stap 3 — Datacontract eerst, frontends later.**
Ik zie te vaak dat visualisatiecode direct op interne objecten (`agent.genoom.g[3]`) prikt; dat breekt bij elke refactor. Ik definieer daarom **stabiele, bevroren dataklassen** (`TikSteekproef`, `GeneratieSteekproef`, `Gebeurtenis`, `RuimtelijkeMomentopname`) met een schemaversie (`evotelemetry/v1`). Elke frontend — matplotlib, Dash, later Grafana of een notebook — consumeert uitsluitend díé contracten.

**Stap 4 — Twee verbruiksmodi, één opslagformaat.**
Er zijn twee fundamenteel verschillende gebruikersscenario's:

1. **Live observatie** ("wat gebeurt er nú?") — lage latentie, tail-weergave, frames mogen vallen.
2. **Analyse/replay** ("waarom crashte run 42 in generatie 17?") — volledige fiducialiteit, scrollen, scrubben.

Beide bedien ik met één formaat: een **append-only JSONL-sink** (elke regel een zelfstandig JSON-object met `soort`-discriminator) plus **ringbuffers** in RAM voor de live-tail. Ringbuffer = backpressure-beleid: het dashboard dat achterloopt laat frames vallen in plaats van de simulatie te blokkeren; de JSONL behoudt altijd volledige historie.

**Stap 5 — Downsampling is een wetenschappelijke vereiste, geen cosmetica.**
Een browser die 20.000 punten per spoor tekent wordt trager dan de simulatie. Maar naïeve stride-downsampling (elk 20e punt) knipt precies de pieken weg waarin je geïnteresseerd bent — een extinctie-uitloop van 3 tikken verdwijnt. Daarom implementeer ik **LTTB (Largest-Triangle-Three-Buckets)**: Downsampling die visuele vormbehoud garandeert binnen een budget van ~900 punten per spoor.

**Stap 6 — Stackkeuze: twee complementeerde frontends in plaats van één zware.**
- **Frontend A — `viz_matplotlib.py`**: nul extra dependencies, één proces, de simulatie loopt *binnen* de render-lus (`FuncAnimation` doet per frame een paar `wereld.stap()`-calls). Ideaal tijdens ontwikkeling; geen threading, dus geen locks.
- **Frontend B — `dashboard_dash.py`**: Plotly/Dash in de browser; simulatie draait in een eigen thread en schrijft onder een lock in de registratie; Dash polled met `dcc.Interval`. Ideeël voor demos en interactieve analyse (zoom, hover, tabbladen, replay-scrubber).

Beide delen dezelfde `TelemetrieRegistratie` — daarmee is de keuze frontend een deployment-kwestie, geen architectuurkwestie.

**Stap 7 — Randgevallen die het ontwerp moeten overleven.**
Totale extinctie (populatie 0 — juist dán wil je kijken wat er gebeurde!), lege buffers bij opstarten, NaN vóór de eerste handelsgebeurtenis (κ is nog ongedefinieerd), thread-races (regel: **kopieer onder de lock, teken buiten de lock**), en geheugenbegroting: een tik-record is ~40 floats ⇒ 20.000 tikken ≈ enkele MB; ruimtelijke momentopnames zijn de enige zware post en krijgen daarom een eigen, kleinere ringbuffer (cap 1500 ≈ 7500 tikken geschiedenis bij cadans 5).

Pas ná deze keten volgt de implementatie.

# ── bestand: evolib/telemetry.py ──────────────────────────────────────────
"""Telemetrielaag: stabiele datacontracten + ringbuffer-registratie +
JSONL-sink. Lees-only t.o.v. de wereld, RNG-vrij, thread-safe."""
from __future__ import annotations

import hashlib
import json
import math
import os
import threading
import time
from bisect import bisect_left
from collections import deque
from dataclasses import dataclass, asdict
from enum import Enum

import numpy as np

from genome import GENE_NAMEN, N_GENES

TELEMETRI_SCHEMA = "evotelemetry/v1"


# ── 1. Datacontracten (bevroren; frontends kennen niets anders) ───────────
class GebeurtenisType(Enum):
    HANDEL_ESCROW = 1
    HANDEL_CREDIT = 2
    WANPRESTATIE = 3
    OVERVAL_WEL = 4
    OVERVAL_MISLUKT = 5
    DOOD_HONGER = 6
    VOGELVRIJ = 7


@dataclass(frozen=True)
class TikSteekproef:
    tik: int
    generatie: int
    populatie: int
    totale_bron: float
    ehi: float
    conflictmult: float
    vruchtbaarheid: float
    vogelvrij: int
    open_schulden: int
    parasitair: float          # aandeel (agressie>.6 & cooperatie<.3)
    coop_ema: float            # NaN vóór eerste relevante gebeurtenis
    gini_erts: float
    shannon: float
    gen_gem: tuple[float, ...]     # lengte 9, volgorde GENE_NAMEN
    gen_std: tuple[float, ...]
    bucket_tellingen: tuple[int, ...]  # lengte 9, index = a*3+c


@dataclass(frozen=True)
class GeneratieSteekproef:
    generatie: int
    beste_fitness: float
    gemiddelde_fitness: float
    n_clusters: int
    hof_top: tuple[tuple[float, tuple[float, ...]], ...]
    component_gem: tuple[float, ...]   # gem. bijdragen: lev/rijkdom/nakom/overl/handel/straf


@dataclass(frozen=True)
class Gebeurtenis:
    tik: int
    type: GebeurtenisType
    actor_ids: tuple[int, ...]
    posities: tuple[tuple[int, int], ...]
    omvang: float


@dataclass(frozen=True)
class RuimtelijkeMomentopname:
    tik: int
    bronnen: tuple[tuple[int, int, int, float], ...]       # x, y, res-int, hoeveelheid
    agenten: tuple[tuple[int, int, int, tuple[int, int], float, bool], ...]
    # id, x, y, bucket, energiefractie, vogelvrij


# ── 2. Metrieken (exacte definities) ──────────────────────────────────────
def gini(waarden: np.ndarray) -> float:
    w = np.sort(np.asarray(waarden, dtype=float))
    n = w.size
    totaal = w.sum()
    if n == 0 or totaal <= 0.0:
        return 0.0
    cumsom = np.cumsum(w).sum()
    return float((n + 1.0 - 2.0 * cumsom / totaal) / n)


def shannon(tellingen: np.ndarray) -> float:
    p = tellingen[tellingen > 0].astype(float)
    tot = p.sum()
    if tot == 0.0:
        return 0.0
    p /= tot
    return float(-(p * np.log(p)).sum())


def lttb(xs: np.ndarray, ys: np.ndarray, m: int = 900) -> tuple[np.ndarray, np.ndarray]:
    """Largest-Triangle-Three-Buckets: downsampling met vormbehoud."""
    n = xs.size
    if m >= n or m < 3:
        return xs, ys
    kx = np.empty(m)
    ky = np.empty(m)
    kx[0], ky[0] = xs[0], ys[0]
    kx[-1], ky[-1] = xs[-1], ys[-1]
    emmer = (n - 2) / (m - 2)
    a = 0
    for i in range(1, m - 1):
        s = min(max(int(math.floor((i - 1) * emmer)) + 1, 1), n - 1)
        e = min(max(int(math.floor(i * emmer)) + 1, s + 1), n)
        sv = min(max(int(math.floor(i * emmer)) + 1, 1), n - 1)
        ev = min(max(int(math.floor((i + 1) * emmer)) + 1, sv + 1), n)
        gem_x = float(xs[sv:ev].mean()) if ev > sv else float(xs[-1])
        gem_y = float(ys[sv:ev].mean()) if ev > sv else float(ys[-1])
        ax, ay = xs[a], ys[a]
        opp = np.abs((gem_x - ax) * (ys[s:e] - ay) - (gem_y - ay) * (xs[s:e] - ax))
        k = s + int(np.argmax(opp))
        kx[i], ky[i] = xs[k], ys[k]
        a = k
    return kx, ky


# ── 3. JSON-hulp (Enum-veilig) ────────────────────────────────────────────
def _json_klaar(o):
    if isinstance(o, Enum):
        return o.name
    if isinstance(o, (tuple, list)):
        return [_json_klaar(v) for v in o]
    if isinstance(o, dict):
        return {k: _json_klaar(v) for k, v in o.items()}
    return o


# ── 4. Registratie ────────────────────────────────────────────────────────
_COOP_GEWICHT = {
    GebeurtenisType.HANDEL_ESCROW: 1.0,
    GebeurtenisType.HANDEL_CREDIT: 1.0,
    GebeurtenisType.OVERVAL_WEL: 0.0,
}


class TelemetrieRegistratie:
    def __init__(self, sink_pad: str | None = None,
                 cap_tikken: int = 20000, cap_gebeurtenissen: int = 60000,
                 cap_ruimtelijk: int = 1500, ruimtelijk_interval: int = 5):
        self.lock = threading.RLock()
        self.tikken: deque[TikSteekproef] = deque(maxlen=cap_tikken)
        self.generaties: deque[GeneratieSteekproef] = deque(maxlen=512)
        self.gebeurtenissen: deque[Gebeurtenis] = deque(maxlen=cap_gebeurtenissen)
        self.ruimtelijk: deque[RuimtelijkeMomentopname] = deque(maxlen=cap_ruimtelijk)
        self.ruimtelijk_interval = ruimtelijk_interval
        self.header: dict = {"schema": TELEMETRI_SCHEMA}
        self._coop_ema = float("nan")
        self._ruimtelijk_teller = 0
        self._sink = None
        if sink_pad:
            self.open_sink(sink_pad)

    # ── sink ─────────────────────────────────────────────────────────────
    def open_sink(self, pad: str) -> None:
        os.makedirs(os.path.dirname(pad) or ".", exist_ok=True)
        nieuw = not os.path.exists(pad) or os.path.getsize(pad) == 0
        self._sink = open(pad, "a", encoding="utf-8")
        if nieuw:
            self._schrijf("header", self.header)

    def koppel_header(self, seed: int, config: dict) -> None:
        self.header.update({
            "seed": int(seed),
            "tijdstip": time.strftime("%Y-%m-%dT%H:%M:%S"),
            "config_hash": hashlib.sha1(
                repr(sorted(config.items())).encode("utf-8")).hexdigest()[:12],
            "config": config,
        })
        if self._sink is not None:
            self._schrijf("header", self.header)

    def _schrijf(self, soort: str, obj) -> None:
        if self._sink is None:
            return
        self._sink.write(json.dumps(
            {"soort": soort, "data": _json_klaar(asdict(obj))},
            allow_nan=True) + "\n")
        self._sink.flush()

    # ── observer-API (door Wereld aangeroepen) ───────────────────────────
    def na_tik(self, wereld) -> None:
        levend = [a for a in wereld.agents.values() if a.levend]
        n = len(levend)
        if n:
            genmat = np.array([a.genoom.g for a in levend])
            gem = genmat.mean(axis=0)
            std = genmat.std(axis=0)
            buckets = np.zeros(9, dtype=int)
            for a in levend:
                buckets[a.bucket[0] * 3 + a.bucket[1]] += 1
            parasitair = float(np.mean([
                1.0 if (a.genoom.waarde("agressie") > 0.6
                        and a.genoom.waarde("cooperatie") < 0.3) else 0.0
                for a in levend]))
        else:
            gem = np.zeros(N_GENES)
            std = np.zeros(N_GENES)
            buckets = np.zeros(9, dtype=int)
            parasitair = 0.0
        bron_tot = wereld.totale_bron()
        ehi = wereld.gov.gezondheidsindex(bron_tot)
        rec = TikSteekproef(
            tik=wereld.tick,
            generatie=wereld.tick // max(1, getattr(wereld, "tick_per_gen", 300)),
            populatie=n, totale_bron=round(bron_tot, 2), ehi=ehi,
            conflictmult=wereld.gov.conflictkostenfactor(wereld._agres_aandeel),
            vruchtbaarheid=wereld.gov.vruchtbaarheidsfactor(ehi),
            vogelvrij=len(wereld.vogelvrij_set), open_schulden=len(wereld.schulden),
            parasitair=parasitair, coop_ema=self._coop_ema,
            gini_erts=gini(np.array([a.erts for a in levend]) if n else np.zeros(1)),
            shannon=shannon(buckets),
            gen_gem=tuple(float(v) for v in gem),
            gen_std=tuple(float(v) for v in std),
            bucket_tellingen=tuple(int(v) for v in buckets),
        )
        with self.lock:
            self.tikken.append(rec)
            self._schrijf("tik", rec)
            self._misschien_ruimtelijk(wereld)

    def na_generatie(self, wereld, motor) -> None:
        arch = list(wereld.generatie_archief)
        if not arch:
            return
        genomen = [g for g, _ in arch]
        stats = [s for _, s in arch]
        tpg = max(1, getattr(wereld, "tick_per_gen", 300))
        f = motor._ruwe_fitness(genomen, stats, tpg)
        w = motor.w
        comp = (
            float(np.mean([(s.levensduur / tpg) * w.levensduur for s in stats])),
            float(np.mean([(s.erts / 40.0) * w.rijkdom for s in stats])),
            float(np.mean([s.nakomelingen * w.nakomelingen for s in stats])),
            float(np.mean([float(s.leeft) * w.overleefd for s in stats])),
            float(np.mean([min(s.handels, 20) / 20.0 * w.handel for s in stats])),
            float(np.mean([-min(s.feiten, 5) / 5.0 * w.feiten_straf for s in stats])),
        )
        rec = GeneratieSteekproef(
            generatie=stats[0].dood_tick // tpg if stats[0].dood_tick else wereld.tick // tpg,
            beste_fitness=float(f.max()), gemiddelde_fitness=float(f.mean()),
            n_clusters=len(set(motor._clustertoewijzing(genomen))),
            hof_top=tuple((round(fit, 4), tuple(float(v) for v in g.g))
                          for fit, g in motor.hof.lijst[:3]),
            component_gem=comp,
        )
        with self.lock:
            self.generaties.append(rec)
            self._schrijf("generatie", rec)

    def gebeurtenis(self, g: Gebeurtenis) -> None:
        wgt = _COOP_GEWICHT.get(g.type)
        if wgt is not None:
            self._coop_ema = wgt if math.isnan(self._coop_ema) \
                else 0.92 * self._coop_ema + 0.08 * wgt
        with self.lock:
            self.gebeurtenissen.append(g)
            self._schrijf("gebeurtenis", g)

    def _misschien_ruimtelijk(self, wereld) -> None:
        self._ruimtelijk_teller += 1
        if self._ruimtelijk_teller % self.ruimtelijk_interval != 0:
            return
        wx, wy = wereld.breedte, wereld.hoogte
        bezet = {(a.pos[0], a.pos[1]) for a in wereld.agents.values() if a.levend} \
            if False else None  # bronnen en agenten staan op dezelfde cel; beide gewoon opnemen
        bronnen = tuple((b.x, b.y, int(b.res), round(b.hoeveelheid, 2))
                        for b in wereld.grid.values() if b.hoeveelheid > 0.05)
        agenten = tuple((a.id, a.pos[0], a.pos[1],
                         (a.bucket[0], a.bucket[1]),
                         round(a.energie / a.max_energie, 3), bool(a.vogelvrij))
                        for a in wereld.agents.values() if a.levend)
        snap = RuimtelijkeMomentopname(tik=wereld.tick, bronnen=bronnen, agenten=agenten)
        self.ruimtelijk.append(snap)
        self._schrijf("ruimtelijk", snap)

    # ── lees-API (kopieer-onder-lock; teken buiten de lock!) ─────────────
    def tik_arrays(self) -> dict[str, np.ndarray]:
        with self.lock:
            buf = list(self.tikken)
        if not buf:
            return {}
        veld = lambda naam: np.array([getattr(r, naam) for r in buf], dtype=float)
        uit = {k: veld(k) for k in
               ("tik", "generatie", "populatie", "totale_bron", "ehi",
                "conflictmult", "vruchtbaarheid", "vogelvrij", "open_schulden",
                "parasitair", "coop_ema", "gini_erts", "shannon")}
        uit["gen_gem"] = np.array([r.gen_gem for r in buf])   # (T, 9)
        uit["gen_std"] = np.array([r.gen_std for r in buf])
        uit["buckets"] = np.array([r.bucket_tellingen for r in buf], dtype=int)
        return uit

    def generatie_lijst(self) -> list[GeneratieSteekproef]:
        with self.lock:
            return list(self.generaties)

    def laatste_ruimtelijk(self) -> RuimtelijkeMomentopname | None:
        with self.lock:
            return self.ruimtelijk[-1] if self.ruimtelijk else None

    def ruimtelijk_in_de_buurt(self, tik: int) -> RuimtelijkeMomentopname | None:
        with self.lock:
            if not self.ruimtelijk:
                return None
            tiks = [s.tik for s in self.ruimtelijk]
            i = bisect_left(tiks, tik)
            i = min(i, len(tiks) - 1)
            return self.ruimtelijk[i]

    def gebeurtenis_matrix(self) -> tuple[np.ndarray, np.ndarray]:
        with self.lock:
            buf = list(self.gebeurtenissen)
        if not buf:
            return np.zeros(0), np.zeros(0)
        return (np.array([g.tik for g in buf], dtype=float),
                np.array([g.type.value for g in buf], dtype=int))

    def recente_gebeurtenissen(self, k: int = 50) -> list[Gebeurtenis]:
        with self.lock:
            buf = list(self.gebeurtenissen)
        return buf[-k:]

    # ── replay ───────────────────────────────────────────────────────────
    @classmethod
    def laad_uit_bestand(cls, pad: str) -> "TelemetrieRegistratie":
        reg = cls()
        enum_terug = {e.name: e for e in GebeurtenisType}
        with open(pad, encoding="utf-8") as fh:
            for regel in fh:
                bericht = json.loads(regel)
                soort, d = bericht["soort"], bericht["data"]
                if soort == "header":
                    reg.header = d
                elif soort == "tik":
                    reg.tikken.append(TikSteekproef(**d))
                elif soort == "generatie":
                    reg.generaties.append(GeneratieSteekproef(**d))
                elif soort == "gebeurtenis":
                    d["type"] = enum_terug[d["type"]]
                    reg.gebeurtenissen.append(Gebeurtenis(**d))
                elif soort == "ruimtelijk":
                    reg.ruimtelijk.append(RuimtelijkeMomentopname(**d))
        return reg

    def sluit(self) -> None:
        if self._sink is not None:
            self._sink.close()
            self._sink = None

def _layout(fig) -> "go.Figure":
    fig.update_layout(template="plotly_dark",
                      paper_bgcolor=DONKER["papercolor"],
                      plot_bgcolor=DONKER["backgroundcolor"],
                      margin=dict(l=36, r=16, t=34, b=28),
                      uirevision="vast")     # behoud zoom/pan tussen polls

class SimulatieRunner(threading.Thread):
    def __init__(self, wereld, stappen_per_slice: int = 25):
        super().__init__(daemon=True)
        self.wereld = wereld
        self.slice_ = stappen_per_slice
        self.stop_event = threading.Event()

    def run(self) -> None:
        while not self.stop_event.is_set():
            for _ in range(self.slice_):
                self.wereld.stap()
            time.sleep(0.002)              # geef de GIL aan het dashboard

                  Input("scrubber", "value") if replay else Input("tabs", "value"),
                  State("tabs", "value"),
                  State("pauze", "value"),
                  prevent_initial_call=False)
    def vernieuw(_n, _x, tab, pauze):
        gestopt = "p" in (pauze or [])
        tik_keuze = _x if replay and isinstance(_x, (int, float)) else None
        if tab == "kaart":
            inhoud = dcc.Graph(figure=fig_kaart(reg, tik_keuze, breedte, hoogte),
                               style={"height": "78vh"},
                               config={"displayModeBar": False})
        elif tab == "reeksen":
            inhoud = dcc.Graph(figure=fig_reeksen(reg), style={"height": "80vh"})
        elif tab == "evolutie":
            inhoud = dcc.Graph(figure=fig_evolutie(reg), style={"height": "86vh"})
        else:
            gf, rijen = fig_gebeurtenissen(reg)
            inhoud = html.Div([
                dcc.Graph(figure=gf, style={"height": "38vh"}),
                dash_table.DataTable(
                    columns=[{"name": c, "id": c} for c in
                             ("tik", "type", "actoren", "omvang")],
                    data=rijen, page_size=18, style_table={"height": "34vh",
                                                           "overflowY": "auto"},
                    style_cell={"backgroundColor": "#161b22", "color": "#c9d1d9",
                                "border": "1px solid #21262d", "fontSize": 12},
                    style_header={"backgroundColor": "#21262d"}),
            ])
        d2 = reg.tik_arrays()
        status = "—" if not len(d2) else (
            f"t={int(d2['tik'][-1])}  N={int(d2['populatie'][-1])}  "
            f"EHI={d2['ehi'][-1]:.2f}  Gini={d2['gini_erts'][-1]:.2f}  "
            f"P={d2['parasitair'][-1]:.2f}  κ={d2['coop_ema'][-1]:.2f}"
            + ("  *** EXTINCT ***" if d2["populatie"][-1] == 0 else "")
            + ("  [gepauzeerd]" if gestopt else ""))
        return inhoud, status

    return app

## Deel 7 — `run_dashboard.py` — bekabeling en moduskeuze

```python
# ── bestand: evolib/run_dashboard.py ──────────────────────────────────────
"""Gebruik:
  python run_dashboard.py --modus live  --seed 42 --generaties 30 [--log runs/r42.jsonl]
  python run_dashboard.py --modus dash  --seed 42 [--log runs/r42.jsonl] [--poort 8050]
  python run_dashboard.py --modus replay --bestand runs/r42.jsonl
"""
import argparse

import numpy as np

from genome import Genome
from telemetry import TelemetrieRegistratie
from world import Wereld
from ecosystem import EcoInstellingen


def bouw_wereld(seed: int, log_pad: str | None) -> tuple[Wereld, TelemetrieRegistratie]:
    rng = np.random.default_rng(seed)
    wereld = Wereld(rng=rng)
    reg = TelemetrieRegistratie(sink_pad=log_pad)
    reg.koppel_header(seed, {
        "breedte": wereld.breedte, "hoogte": wereld.hoogte,
        "eco": vars(wereld.gov.inst), "tick_per_gen": wereld.tick_per_gen})
    wereld.observers.append(reg)
    for _ in range(110):
        wereld.spawn(Genome.willekeurig(rng))
    return wereld, reg


def main() -> None:
    ap = argparse.ArgumentParser()
    ap.add_argument("--modus", choices=("live", "dash", "replay"), default="live")
    ap.add_argument("--seed", type=int, default=42)
    ap.add_argument("--log", default=None)
    ap.add_argument("--bestand", default=None)
    ap.add_argument("--poort", type=int, default=8050)
    args = ap.parse_args()

    if args.modus == "replay":
        assert args.bestand, "--bestand vereist voor replay"
        reg = TelemetrieRegistratie.laad_uit_bestand(args.bestand)
        from dashboard_dash import maak_app
        app = maak_app(reg, replay=True)
        app.run(port=args.poort, debug=False)
        return

    wereld, reg = bouw_wereld(args.seed, args.log)
    if args.modus == "live":
        from viz_matplotlib import MatplotlibViewer
        try:
            MatplotlibViewer(wereld, reg).run()
        finally:
            reg.sluit()
    else:
        from dashboard_dash import SimulatieRunner, maak_app
        runner = SimulatieRunner(wereld)
        runner.start()
        app = maak_app(reg, wereld=wereld)
        try:
            app.run(port=args.poort, debug=False)
        finally:
            runner.stop_event.set()
            reg.sluit()


if __name__ == "__main__":
    main()
```

## Deel 9 — Randgevallen, backpressure en prestatiebudget

**Backpressure-beleid (wat mag vallen?):**

| Kanaal | Beleid | Reden |
|---|---|---|
| Ruimtelijke momentopnames (RAM) | ringbuffer 1500 → oudste valt | zwaarste post; kaart heeft maar de tail nodig |
| Tik-steekproeven (RAM) | ringbuffer 20.000 | ~40 floats/stuk ⇒ ~6 MB bovengrens |
| Gebeurtenissen (RAM) | ringbuffer 60.000 | tail-weergave |
| **JSONL-sink** | **valt nóóít** | volledige fiducialiteit voor replay/analyse |

**Determinisme:** de registratie gebruikt geen enkele RNG, mutueert niets in `Wereld`, en de header bevat `seed` + `config_hash` — elk JSONL-bestand reconstrueert exact de run die het beschrijft. Visualisatie-jitter (bijv. in matplotlib) zou, indien ooit nodig, een *eigen* `Generator(seed)` krijgen, nooit de globale toestand.

**Threadsafety-regel voor Dash:** elke callback doet `reg.<lees-API>()` — die kopieert intern onder de `RLock` — en bouwt Plotly-figuren *buiten* de kritieke sectie. Nooit een referentie naar een deque-element buiten de lock gebruiken (immutable dataclasses maken dit veilig).

**Degenerate toestanden:** populatie 0 → kaart krijgt "EXTINCT"-titel, statusregel krijgt een banner, alle delingen in `gini`/`shannon`/`np.divide` hebben expliciete nul-guards; κ is `NaN` tot de eerste handels-/roofgebeurtenis en wordt in beide frontends door de mediaan vervangen vóór plotting.

**Prestatiebudget:** `na_tik` kost O(N + 9) ≈ microseconden bij N=110; ruimtelijke opname O(|grid| + N) elke 5 tikken; LTTB begrenst browsersporen op 900 punten; `uirevision="vast"` voorkomt dat zoom/pan elke poll-reset. De matplotlib-frontend haalt comfortabel 15–20 fps met `spf=4`; wil je sneller simuleren dan kijken, zet je `--modus dash` uit en draai je headless naar JSONL, en bekijkt de replay daarna.

## Deel 10 — Extensieroute (in volgorde vanwetenschappelijke opbrengst)

1. **Faseportret-paneel** `(P_parasitair, EHI)` — direct bewijs/ weerlegging van de demping uit verdedigingslinies L2/L3.
2. **Fylogenie-weergave** — per generatie een hiërarchische clustering (UPGMA op genoomafstand) van het archief, gerenderd als icicle/sunburst: zichtbaar waar parasitaire clades ontstaan en uitsterven.
3. **Multi-run-overlay** — meerdere JSONL-bestanden in één Dash-sessie laden; identical-schema maakt A/B-vergelijking van gouverneursparameters (`vruchtbaar_drempel`, `conflict_cap`) triviaal.
4. **Ops-adapters** — een tweede observatorklasse die hetzelfde protocol naar Prometheus-counters vertaalt, geeft gratis Grafana-dashboards voor langlopende batch-experimenten; de architectuur hoeft daarvoor niets te veranderen — dat is precies de return op de investering in het smalle observer-protocol en de bevroren datacontracten.
